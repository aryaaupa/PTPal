# Vitalize PT Design System

- Mood: calm, clinical, encouraging
- Tokens: see `packages/config` and CSS variables injected by `@vitalize/ui`
- Components: Button (primary/outline/ghost), Card, Input, Modal, Toast, ProgressRing
- Motion: hover 120ms, tap 80ms; respects reduced motion
- Accessibility: WCAG AA, labels, large tap targets

## Tokens
- bg0, bg1, text1, text2, brand, brand2, accent, ok, warn, danger, border
- Radius: 16px; Shadow: soft

## Usage
```tsx
import { ThemeProvider, Button, Card } from '@vitalize/ui';
```
